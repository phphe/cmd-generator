zip

打包和压缩文件为 zip 格式。

$ zip -6

示例

# 创建压缩包
zip archive.zip file1.txt file2.txt

# 递归目录
zip -r archive.zip /path/to/dir

# 最高压缩
zip -9 archive.zip largefile.iso

# 更新已有
zip -u archive.zip file.txt

# 列出内容
unzip -l archive.zip
